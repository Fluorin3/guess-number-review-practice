## Описание проекта

Данный проект - игра, написанная на языке программирования python. В ней вы угадывается случайно загаданное число от 1 до 100

## Алгоритм работы

1. Загадывает число от 1 до 100 (или просит пользователя ввести секретное число).
2. В цикле while спрашивает у пользователя догадку.
3. Подсказывает «больше» / «меньше» / «угадал».
4. Считает количество попыток и выводит его в код

## Как запустить

Команда в терминале `python3 game.py`

## Описание кода

Данный код - продукт процедурного программирования, написанный на python версии 3.14.2.
Логика: все действия идут последовательно. Полное отсуствие ООП ввиду простоты программы.

## Алгоритм работы кода

1. Ипморт библиотеки random, необходимой, чтобы задать случайное число.
2. Введение случайного чила.
3. Цикл: пока человек не угадает число, программа не закончит своё выполнение. Каждую попытку начисляется балл.
4. Цикл подсказывает с помощью условных операторов близость и отдалённость пользователя от загаданного числа.
5. Когда пользователь угадывает, программа выводит число попыток и выходит из цикла, тем самым завершая своё выполнение.
